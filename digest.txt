1. EXECUTIVE SUMMARY & NON-NEGOTIABLE ARCHITECTURAL RULES
--------------------------------------------------------------------------------
- Purpose: AI-powered UPI dispute management platform that classifies complaints,
  checks transaction consistency, and recommends explainable advisory resolutions.
- Non-negotiable Rules (AGENTS.md):
  1. AI recommends; humans decide. Execution mode is strictly ADVISORY_ONLY.
  2. Keep ML classifier (app/ml), Consistency rules (services/consistency.py),
     and Resolution rules (services/resolution.py) separate.
  3. Never fabricate metrics or confidence values. Report AI_UNAVAILABLE if missing.
  4. Roles (CUSTOMER, SUPPORT_AGENT, ADMIN) come from database JWT claims, server-enforced.
  5. Provenance tags: SYNTHETIC, USER_IMPORTED, PROVIDER_VERIFIED.
  6. No PINs/OTPs logged or stored. Raw text omitted from audit details.
  7. Case status transitions strictly via services.cases.transition.

3. NEW CORE CAPABILITIES IMPLEMENTED
--------------------------------------------------------------------------------
A. Official Fintech Landing Page with Live Simulator:
   - Clean, official corporate fintech layout replacing neon cyber aesthetics.
   - Interactive Live Dispute Scenario Simulator testing real-world UPI failure cases.

B. Dual Theme Architecture:
   - Light Theme enabled by default with seamless toggle to Dark Theme via
     header and sidebar Sun/Moon controls.
   - LocalStorage persistence and Tailwind class-based dark mode (`darkMode: "class"`).

C. One-Click Official Dispute Dossier Export (PDF/Print):
   - Generates formatted, audit-ready dispute documentation formatted for submission
     to the bank ombudsman or NPCI dispute mechanism. Includes case IDs, RRN codes,
     switch statuses, rule findings, and immutable audit trails.

D. Bank SMS & WhatsApp Alert Parser:
   - Parses raw debit alerts (e.g. "Rs.1500 debited... Ref 123456") to automatically
     populate disputed amounts, bank references, and payee VPAs.

E. Interactive 5-Step Dispute Filing Wizard:
   - Visual step progress indicators (Steps 1 to 5), input length checks,
     drag-and-drop evidence uploads, and optional AI-assisted classification.

F. Admin Turnaround SLA Tracker:
   - Real-time resolution SLA counter benchmarked against the official
     48-hour NPCI turnaround guideline with visual status compliance indicators.
